# Airport surface assets

Locally hosted, unmodified 1K assets from [Poly Haven](https://polyhaven.com).
All are released under [CC0](https://polyhaven.com/license), permitting reuse and
redistribution. No runtime CDN requests are needed. The full download URLs,
byte sizes and verified upstream MD5 hashes are in `manifest.json`.

| Local files | Source |
| --- | --- |
| `concrete-color.jpg`, `concrete-normal.jpg`, `concrete-roughness.jpg` | [Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02) |
| `asphalt-color.jpg` | [Asphalt 02](https://polyhaven.com/a/asphalt_02) |
| `daylight.hdr` | [Kloofendal 48d Partly Cloudy Puresky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) |

The four JPEG maps and HDR total about 3.3 MiB on disk. Colour maps use sRGB;
normal and roughness maps use linear data. Texture sampling is shared, repeat
wrapped and limited to 4× anisotropy. The HDR lights and reflects in surfaces;
it is not the visible background. These are decorative surface assets, not
airport imagery or operational evidence.
